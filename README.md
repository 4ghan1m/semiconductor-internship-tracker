# 芯途 · 半导体实习监测

网页：https://4ghan1m.github.io/semiconductor-internship-tracker/

每天北京时间 **05:00** 检索公开半导体实习岗位，材料工程硕士与北京优先。页面支持岗位搜索、只看北京、四类状态筛选，以及日期倒序历史。

## 运行方式

`.github/workflows/daily.yml` 在默认分支启用 `schedule` 和 `workflow_dispatch`。`0 21 * * *` 采用 UTC，对应次日北京时间 05:00。GitHub 调度存在排队和延迟，无法保证整点完成；网页显示每轮真实更新时间。可从 Actions 手动运行。

工作流先测试，再实时检索、保存快照、提交历史，最后发布同一个 `docs/index.html` 到 Pages。更新提交不触发自身；串行运行避免覆盖。无需付费搜索 API、模型密钥或第三方托管账号。

## 检索与证据

- 扫描应用材料、KLA、Intel、NXP 官方 Workday 招聘库，分页读取并核对中国实习详情。
- 六组网页搜索补充北京、材料、工艺及国内半导体企业线索；关键词和来源在 `config.json` 可编辑。
- 北京材料方向的已知线索也保留实时复核，访问失败归为待核实。
- 官方职位编号、详情、申请地址、`canApply=true` 和 `posted=true` 同时满足，才确认 Workday 岗位开放。
- 搜索摘要仅用于发现；不作为开放证据。网页必须有职位级详情、有效截止日期及投递入口才能自动确认。
- 报告每个来源的成功、失败、扫描量；来源异常不会清空已有记录。所有来源均失败时仍先保存并发布异常提示，然后令工作流失败，方便查错。

检索并非全网覆盖。中文招聘网站的验证码、登录限制及来源结构变化可能导致漏检；它们不会被伪装成“已关闭”。专业匹配是可解释的关键词排序，最终学历、技能、出勤等资格以原职位为准。偏软件岗位会明确标注技能门槛。

## 状态约束

1. **新发现开放**：本系统首次取得实时开放证据的日期内。
2. **仍在招聘**：此前已推荐确认开放，本轮再次核实开放。
3. **已关闭**：必须有本系统此前的 `recommended_at`，之后取得明确关闭证据。新发现时就已关闭的岗位完全不入库。官方明确不可申请且不再发布、明确的职位关闭标记或职位截止日期，才可能成为关闭证据。
4. **待核实**：未经实时证实的线索，或本轮访问/解析失败的既有岗位。404、搜索消失、登录墙、超时均不推断关闭。

## 数据与历史

`data/registry.json` 为持久岗位账本；`recommended_at`、`last_confirmed_open`、状态事件及关闭证据不会因下一次检索丢失。

`data/runs/<timestamp>-<run-id>-<attempt>.json` 是每次运行的独立完整快照，不允许同名覆盖。`data/history/YYYY-MM-DD.json` 追加该日的运行索引，`data/latest.json` 是本轮数据。页面按日期倒序展示每日最后快照，同时提供同日每次运行的完整数据。所有历史同步进入 `docs/data/` 并提交到 Git；不做自动裁剪。

首次部署只有真实运行当天的记录。跨日与重复运行测试只在临时目录使用合成数据，不向真实历史添加虚构日期或岗位。

## 本地维护

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python tracker.py
# 不检索，仅用已有历史重新生成页面
python tracker.py --render-only
```

Pages 发布来源需设为 **GitHub Actions**。源码、配置和公开招聘证据均在此仓库，不应加入个人简历、联系方式或任何账号密钥。
